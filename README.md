# 📺 ALIVE 라이브 플레이어 플러그인 (v1.2.1)

BookOasis 미디어 서버의 공식 저수준 프록시 API(`getProxyUrl`, `getStreamProxyUrl`)를 완벽하게 준수하여 실시간 IPTV 스트리밍 및 다중 EPG 편성표를 제공하는 풀페이지 플러그인입니다.

---

## ✨ 핵심 기능

1. **상단 UI 정돈 & 소스 관리 모달**:
   * 상단에 복잡한 URL 노출 없이 직관적인 툴바 제공 (`[📚 ⚙️ 소스 관리]`, `[🩺 상태 점검]`, `[🔄 새로고침]`)
2. **복수 M3U 플레이리스트 관리**:
   * 주소 입력창 1 및 주소 입력창 2를 동시에 등록하여 채널 자동 병합 로딩
3. **다중 EPG 우선순위 & 자동 갱신**:
   * EPG 1(최우선) → EPG 2(차순위/백업) 순차 매핑
   * 30분, 1시간, 12시간, 24시간 백그라운드 자동 갱신 타이머 탑재
4. **실시간 스트림 상태 점검 (Health Check)**:
   * 원클릭으로 활성 채널들의 스트림 가용성을 비동기 검사하여 🟢(온라인)/🔴(오프라인) 상태 뱃지 표시
5. **즐겨찾기 (Favorites)**:
   * 채널별 ⭐ 즐겨찾기 토글 및 `⭐ 즐겨찾기` 전용 필터 뷰 제공
6. **BookOasis 8종 테마 실시간 동기화**

---

## 🚀 사전 필수 설정 (외부 도메인 등록)

BookOasis의 보안 규격에 따라, 플러그인이 외부 스트림 서버나 EPG 서버에 접근하기 위해서는 해당 도메인을 관리자 설정에 등록해야 합니다.

1. BookOasis 웹 UI 상단의 **[관리자 설정 ⚙️]** → **[외부 도메인]** 탭으로 이동합니다.
2. M3U, EPG 및 스트림 원본 도메인을 등록합니다.
3. **[추가]** 후 저장합니다.

---

## 🛠️ 사용 방법

1. 좌측 사이드바의 **ALIVE 플레이어** 메뉴를 클릭합니다.
2. 상단의 **`[📚 ⚙️ 소스 관리]`** 버튼을 클릭하여 M3U 주소(1, 2)와 EPG 주소(1, 2)를 입력하고 **[저장 및 적용]**을 누릅니다.
3. **`[🩺 상태 점검]`** 버튼을 눌러 방송 스트림이 정상 송출 중인지 확인합니다.
4. 자주 보는 채널의 **⭐ 별 아이콘**을 클릭해 즐겨찾기에 등록합니다.
